# Steam screenshots

The ZIP contains exactly ten 1920 × 1080 PNGs. Upload the numbered images to Steam in order, or reorder them as desired.

Every image was captured directly from the running production game in an isolated QA session with the native HUD visible, VHS enabled, and CRT disabled. Camera placement and encounter timing were directed using the game’s existing scenes, assets, and effects. No compositing, retouching, color grading, or resizing was applied to the upload images. The contact sheet is only a resized preview and is not in the ZIP.

The capture manifest records the source frame, engine settings, camera, and SHA-256 checksum of each upload. The capture script is `tools/capture_steam_screenshots.gd`.
