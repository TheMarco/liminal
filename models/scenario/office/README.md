# Office asset set

These models and surface maps were made for the Office level through Scenario
and reviewed in September 2026. The visual direction is a clean, clinical
1980s office. The archive box uses the approved brown kraft-cardboard finish.

The furniture and fittings mix image-to-3D meshes with exact hard-surface
geometry dressed in generated materials. Large image-to-3D meshes were reduced
for runtime use while retaining the approved silhouette and embedded textures.
The `carpet_tile`, `drywall_panel`, and `ceiling_tile` GLBs are source samples;
their approved finishes are mapped onto the level's continuous generated
surfaces so room boundaries and the 0.75 m ceiling grid remain seamless.

The elevator is deliberately outside this replacement set.

The open doorway casing's header ends flush with the jambs (2.51 m outer
width). Its runtime fitting preserves the previous jamb positions and clear
opening; only the former 2.5 cm overhang at each end has been removed.
