# Colored pool mattress

User-supplied `orange_pool_float.glb`, modeled in Blender from an approved product render. The model is approximately 0.79 m wide, 1.85 m long, and 0.20 m high. Poolrooms retains its modeled seams and normal map while tinting its two vinyl materials to one of ten seeded colors. It uses a surface-locked rigid body so the player can push it.
