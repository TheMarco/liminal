# Execution table

- **Title:** `Execution Table Game LowPoly`
- **Creator:** Supplied directly by the project owner on 2026-09-17 (source
  file `Execution_Table_Game_LowPoly.glb`, replaced by optimized
  `Execution_Table_Game_LowPoly_512.glb` the same day).
- **License:** Project-owned asset supplied for use as embedded game content.
- **Local file:** `execution_table.glb`
- **Authored specification:** Metres, Y=0 at the floor. A lethal-injection
  gurney, 2.06 m across the armboards and 2.23 m long, 1.27 m tall, with
  pedestal base and column, main frame, head and body cushions, armboards,
  leather restraints, buckles and padded wrist cuffs; the head cushion
  sits at local -Z. Forty meshes at 22,454 triangles with eighteen packed
  PNG textures extracted at import. No authored lights.
- **Modifications:** The supplied static GLB is retained unchanged. Runtime
  uses it at native scale, centred, laid across the dais in execution-table
  takeovers of merged guard, industry, visitation and rotunda rooms.
