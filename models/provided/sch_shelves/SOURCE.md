# School library shelves

- **Title:** `School library double shelves`
- **Creator:** Supplied directly by the project owner on 2026-09-18 (source
  file `school_library_double_shelves_game.glb`).
- **License:** Project-owned asset supplied for use as embedded game content.
- **Local file:** `sch_shelves.glb`
- **Authored specification:** Metres, Y=0 at the floor. A double-bay shelf
  unit, 3.55 m long, 2.12 m tall and 0.47 m deep, with books facing local
  +Z and oak back panels at local -Z. Twenty-eight meshes at 30,136
  triangles with packed JPG/PNG textures extracted at import. No authored
  lights.
- **Modifications:** The supplied static GLB is retained unchanged. Runtime
  places two units back to back per run so books face both aisles, at
  native scale and centred.
