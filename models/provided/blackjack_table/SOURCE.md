# Royal blackjack table

- **Title:** `royal_blackjack_table`
- **Creator:** Supplied directly by the project owner on 2026-09-17 (source
  file `royal_blackjack_table.glb`).
- **License:** Project-owned asset supplied for use as embedded game content.
- **Local file:** `blackjack_table.glb`
- **Authored specification:** Higher-detail supplied model in metres, Y=0 at
  the floor. The table body is
  2.52 m wide with a felt top at about 1.05 m and a 1.67 m deep footprint
  centred near the origin; the card shoe rides on the dealer edge and seven
  chairs ring the player arc at roughly 1.45 m radius. About 9,500 triangles
  per set, with a packed base-color/normal/ORM texture set extracted at
  import.
- **Modifications:** The supplied static GLB is retained unchanged. Runtime
  uses it at 85% scale so its 1.20m overall height aligns with the replacement
  roulette table, while preserving the casino's established placement,
  player-arc orientation and fixture metadata. The collider covers the table
  body only, so the player can still walk between the chairs.
