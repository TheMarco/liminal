# Striped pool float

User-supplied `striped_pool_float_game.glb`. The imported ring is approximately
1.11 m wide and 0.27 m high. Poolrooms keeps its modeled rope, valve, normal
map, and roughness map. The alternating vinyl panels and matching welds use
seeded light/dark color pairs. It shares the light, pushable floating behavior
of the other Poolrooms floats.
