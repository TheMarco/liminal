- **Modifications:** Authored at real-world scale (1.18 x 0.79 x 2.37 m) and
  placed unscaled, floor-aligned from measured bounds with conservative
  collision. Despite its name it is an autopsy table — fluted drainage top,
  castors, undershelf — so it is restricted to asylum treatment rooms, set off
  to one side of the restraint table. Embedded textures re-encoded at 1024 px;
  mesh and material unchanged.

The same creator's work appears in this project as the two prison doors.
