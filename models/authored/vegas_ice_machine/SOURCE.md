# vegas_ice_machine

Original Blender model authored for this game from the user's supplied visual reference. No reference photograph pixels are used as textures.

- Source: art/vegas_ice_machine/vegas_ice_machine.blend
- Rebuild: Blender --background --python tools/blender/build_ice_projector.py -- ice
- 2,561 triangles; 2 material surfaces.
- Metres, +Y up, +Z front; base on the floor (projector base placed on tabletop).
- One 1024² baked base-color/normal/ORM set. Ice machine also has a compact printed nameplate.
- Reference geometry: distinct manufactured surfaces, bevelled silhouette and modeled hardware.
