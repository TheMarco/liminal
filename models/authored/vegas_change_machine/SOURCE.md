# Vegas change machine

Original Blender model created for this project from the user-supplied visual reference. No photo pixels or third-party model geometry are included.

- Blender source: art/vegas_change_machine/vegas_change_machine.blend
- Rebuild: tools/blender/draw_vegas_change_art.py then Blender tools/blender/build_vegas_change_machine.py
- Units: metres. Y=0 at the floor; +Z faces the customer.
- 1,946 triangles, two mesh surfaces. Body uses baked 1K PBR maps; face printing uses one 1K image.
- Runtime bounds: 1.072m wide × 1.736m tall × 0.668m deep.

Revised from the clearer reference: raked front and lower door, sloping metal shelf with one cut-in left coin cup and a small rectangular right return well, framed bill panel and oversized CHANGE header.
